# LC Venture Holdings — Ticket Intelligence Platform

## Deploy to Vercel (10 min) then install as iPhone app

---

### STEP 1 — GitHub (free)
1. Go to github.com → Sign up
2. Click "+" → New repository
3. Name: lcventure-holdings | Set to Private | Click Create
4. Click "uploading an existing file"
5. Unzip this folder and drag ALL files into GitHub
6. Click "Commit changes"

---

### STEP 2 — Vercel (free)
1. Go to vercel.com → Continue with GitHub
2. Click "Add New Project"
3. Select lcventure-holdings
4. Click Deploy (auto-detects Vite/React — no config needed)
5. You get a live URL: lcventure-holdings.vercel.app

---

### STEP 3 — Install on iPhone (PWA)
1. Open your Vercel URL in Safari on your iPhone
2. Tap the Share button (box with arrow at bottom)
3. Scroll down → tap "Add to Home Screen"
4. Name it "LC Venture" → tap Add
5. The app icon appears on your home screen
6. Opens full screen like a native app — no browser bar

---

### STEP 4 — Also install on Desktop (optional)
Open in Chrome → 3-dot menu → Save and share
→ Create shortcut → check "Open as window" → Add
Now it's a desktop icon too.

---

## Features
- Dashboard with full P&L
- Live Ticket Search with AI market analysis
- Inventory tracker (seats, cost, resale value, client)
- Expense tracker (parking, transport, hospitality, etc.)
- Price Alerts with sound notifications
- Profit & Loss by event
- Works offline (PWA)
